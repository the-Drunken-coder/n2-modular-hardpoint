# Recorded R4 local validation

This directory records a completed **local development run**, with exact input/result provenance. It is documentary evidence, not an input or substitute for the fresh GitHub Actions workflow.

Read [report.md](report.md) for numerical findings, [summary.json](summary.json) for every mesh/case, and [validation-gate.json](validation-gate.json) for the automated checks. [fit-stack.json](fit-stack.json) records explicit fit assumptions; [bench-status.json](bench-status.json) records that physical measurements are pending.

No payload rating, flight qualification, measured material properties or physical loaded-release success is claimed.
