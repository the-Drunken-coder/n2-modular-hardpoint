# Physical measurements pending

Every CSV in this directory is a header-only template. No physical trial has been run, and there are no measured results or pass claims here. Blank means unknown, not zero.

Follow H1–H5 in [the concept verification note](../../../../docs/concept-verification-20261029.md). Use consistent specimen/instrument identifiers and timestamps. Record units as named in headers; reference raw force/displacement/current/video/vibration files instead of replacing them with only a peak value. State measurement uncertainty and the exact accepted criterion in each trial.

The legacy 8.9 N and 17.8 N axial targets remain provisional. Fill target fields only after deciding the actual test inputs. Do not prefill outcome fields from simulation, a manufacturer's endpoint force, or a successful controller pulse.
