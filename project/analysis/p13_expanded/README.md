# P13 expanded sims

Summary and tables: [docs/p13-expanded-sims.md](../../../docs/p13-expanded-sims.md).

- `results.csv`: every case (component, case, failure N, rating at SF 3, margin vs 4.0 N, 0.4/0.8 mm regularized values, peak location).
- `results/`: solver JSON per case (fields npz not kept; regenerate with the configs).
- `configs/`: solver configs (generated by `gen.py` from the archived configs). Off-axis cases are named `<case>__<plane><sign><deg>`.
- `aniso.json`: reduced-interlayer-strength check (`post.py`).
- `convergence.json`: mesh check on the governing case.
Solver: `inputs/drivers/solver_6d9b172….py`, run as `python solver.py --config <cfg> --sizes 0.55`.
