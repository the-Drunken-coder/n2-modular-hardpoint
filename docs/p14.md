## R4 / R5d: straight-pull FEA, PAHT-CF

Frozen linear solver, PLA-screen failure × 47/31, via `tools/n2fea.py --prox bridge` and the repo keeper config (anchors moved to the new underside). Data: `project/analysis/p14/fea/`.

| Part, case | Failure (N) | vs 17.8 N |
|---|---:|---:|
| Adapter, keeper-floor load | **33.68** (governs) | 1.89× |
| Receiver, both roofs | 59.17 | 3.32× |
| Receiver, **distal roof lost** | **36.73** | 2.06× |
| Keeper, both roofs | 114.9 | 6.5× |
| Keeper, distal lost | 71.6 | 4.0× |
| Keeper, half-width contact | 57.4 | 3.2× |

**Worst credible engagement (distal lost): 33.68 N, governed by the adapter**, the same part and number as with full engagement. Rating at SF 2: 16.8 N straight pull (was 9.1 N). P13 for comparison: 18.33 N governed by the distal-lost receiver. ~7% mesh scatter applies.

**R5d:** losing the 0.6 mm distal overlap (tolerance, wear, partial travel) no longer reduces capacity: the governing failure is unchanged. The partial state still exists geometrically but has no capacity penalty, and it is within the 3 mm stroke.

Alternatives run (same tool, bridged roof): lug 1.2 / overlap 0.8 gives 30.2 N adapter, 35.9 N distal-lost; lug 1.0 / overlap 1.0 gives 25.7 N adapter. A thinner lug costs adapter strength for no benefit, so 1.4/0.6 stays. Off-axis capacity remains low (adapter 4.3 N at 90°) and is not required (R3).

## R5c: back-drive (analysis)

Assumptions: contact faces are horizontal, load is +Z, keeper moves in X. The load can only push the keeper in X if the contact tilts more than atan(μ). Assume μ = 0.2 (dry printed polymer, low end) → 11.3°.

Tilt bound: sum of peak displacements per N (adapter 0.00183, receiver distal-lost 0.00119, keeper distal-lost 0.00136 mm/N) × 8.9 N = 0.039 mm, over a 1 mm patch (lug is 1.4 mm) → 2.2°. Doubled for a PAHT-CF Z modulus possibly half of the PLA value used: 4.5°. That is 2.5× below the friction angle, and it uses peak (not differential) displacement, so it is conservative. The spring preload adds further resistance.

**Verdict: PASS on analysis**, untested. The back-drive test in R5 is still required.

## R5e: vibration (analysis)

Assumptions: 2 g peak in any direction including X (R2), friction ignored (conservative: under load the payload clamps the keeper). Moving mass = keeper 449.5 mm³ × 1.2 g/cm³ = 0.54 g, plus armature unknown, bounded by the whole Adafruit 2776 (12.6 g). Total ≤ 13.1 g.

Required spring preload at the latched position: 13.1 g × 2 × 9.81 = **0.26 N** (26 gf). With SF 2: **0.52 N**. The solenoid is rated 80 g (0.78 N) at 5 V, so the preload must also stay below what it can overcome.

**Verdict: PASS only if the measured return-spring preload is ≥ 0.26 N (target ≥ 0.52 N) and the solenoid still unlocks.** The stock spring force is not published: measure it at the latched position. A vibration test is still required.
