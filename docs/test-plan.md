# R5 bench acceptance plan

This is the active **R5** test entry point. [P14's solenoid plan](p14-test-plan.md) is historical and does not qualify R5.

Before loaded trials, complete R5 print inspection, purchased-part fit, defined crank-pin assembly and servo calibration. Record exact geometry/source revision, filament process, hardware and fixture. Use the [current requirements](requirements.md).

The complete-assembly retention proof target is **17.8088764 N**. Required loaded release is **8.9044382 N** axial −Z extraction. Observe command, actual keeper clearance, actual adapter departure and reset separately. A command or visible horn movement alone does not pass release.

**Physical evidence remains pending.** A revision-specific campaign must define specimens, repetitions, dwell/clearance timing, inspection, power measurements and rejection criteria before assigning any operating envelope. Generated CAD/FEA results cannot mark physical tests complete.
